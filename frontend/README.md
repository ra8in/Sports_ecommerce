# SportShop - Frontend App

This is the front-end interface for the **SportShop** e-commerce platform. It is built to be extremely fast and responsive using modern web technologies.

## Tech Stack

- **React 19** 
- **Vite** (Build Tool & Dev server)
- **React Router DOM** (Routing)

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Running

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Run linter:**
   ```bash
   npm run lint
   ```

## API Connection

Ensure the Django backend is running at `http://127.0.0.1:8000/` for the frontend to successfully communicate with the APIs. Configure your environment variables to point out to the correct backend host when preparing for a production build.
